## How to read the columns

Keys: Tab and Shift+Tab move focus, Enter and Space act, arrow keys change a select or radio. Focus order lists what Tab should reach, in order. Visible focus means a clear outline on every stop that is not hidden behind a sticky header or banner (WCAG 2.4.7, 2.4.11); also write Fail if focus ever lands on nothing. Live text is what the screen reader should say when the text appears, without moving focus. Result: Pass, Fail or Skipped, plus a note.

## 400 px pass

Set the window to 400 CSS pixels wide (or zoom a 1280 px window to 320 percent) and repeat steps 1, 4, 8, 15, 16, 19 and 22. Pass when no horizontal page scroll is needed, focus never lands under a sticky element, the tab order is the same as at full width, and every control is reachable. Record any step that loses information.
